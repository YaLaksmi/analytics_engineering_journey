# 04_pandas: Анализ розничных продаж (Online Retail II)

**Автор:**   
**Источник данных:** Online Retail II (UCI Machine Learning Repository)  
**Инструменты:** Python, Pandas, Matplotlib, Seaborn

---

## 🎯 Цель проекта

Продемонстрировать навыки анализа данных с использованием Pandas на реальном датасете онлайн-ритейла.

---

##  Источник данных

- **Название:** Online Retail II
- **Описание:** Транзакции интернет-магазина за 2009–2011 годы
- **Ключевые поля:** Invoice, Customer ID, StockCode, Quantity, Price, InvoiceDate, Country

---

##  Основные этапы анализа

### 1. Подготовка и очистка данных
- Загрузка и первичный осмотр
- Удаление строк с пустым Customer ID
- Фильтрация Quantity > 0 и Price > 0
- Удаление дубликатов
- Преобразование InvoiceDate в datetime
- Создание колонки TotalPrice = Quantity * Price

### 2. Исследовательский анализ (EDA)
- Динамика продаж по месяцам (пик в ноябре-декабре)
- Топ-10 товаров по выручке (JUMBO BAG, REGENCY CAKESTAND)
- Топ-10 стран (Великобритания > 80% выручки)

### 3. RFM-сегментация
- Recency: дни с последнего заказа
- Frequency: количество заказов
- Monetary: общая сумма покупок
- Сегменты: Champions, Loyal, At Risk, Lost, New

### 4. Когортный анализ (удержание)
- Cohort = месяц первого заказа клиента
- Расчёт Retention Rate по месяцам жизни когорты
- Вывод: резкое падение удержания после 1-го месяца
