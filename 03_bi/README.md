# Online Retail Analytics | Power BI проект

Анализ транзакций интернет-магазина: когорты, клиенты, товары, география и динамика

Power BI | DAX | Модель "Звезда"

---

## О проекте

Проект представляет собой аналитический дашборд для интернет-магазина на основе открытого датасета Online Retail II. Цель — исследовать поведение клиентов, выявить ключевые метрики и построить когортный анализ удержания.

Датасет: транзакции за 2009-2011 гг. (UK-based retailer)

---

## Бизнес-задачи

- Анализ общей динамики продаж (KPI, тренды, сезонность)
- Когортный анализ удержания клиентов (по неделям, месяцам, годам)
- Сегментация клиентов (RFM, VIP, Regular, One-time)
- ABC-анализ товаров (категории A, B, C по выручке)
- Географический анализ продаж (карта, топ стран)
- Time Intelligence (MoM, YoY, YTD, скользящие средние)

---

## Модель данных

Схема "Звезда":

- Dim Date - календарь
- Dim Customers - клиенты (сегменты, RFM)
- Dim Products - товары (категории, ценовые сегменты)
- Dim Country - страны (континенты)
- Sales - таблица фактов (транзакции)

---

## Страницы дашборда

1. Общая аналитика - KPI, динамика продаж, топ-10 стран и товаров
2. Когортный анализ - Retention Rate по дням, неделям, месяцам, годам
3. Клиентская аналитика - RFM, сегменты, частота покупок
4. Товарная аналитика - топ-15 товаров, Парето (80/20)
5. ABC-анализ - деление товаров на категории A, B, C по выручке
6. Геоаналитика - карта продаж, топ стран, динамика по странам
7. Динамика показателей - YTD, MoM, YoY, скользящие средние

---

## Особенности реализации

- Неактивная связь между Dim Date и Dim Customers для фильтрации когорт
- Параметры полей для переключения строк, столбцов и метрик в когортах
- Вычисляемые колонки для RFM, групп Recency и Monetary, бинов заказов
- Условное форматирование матриц и тепловых карт

## Запуск проекта

Требования:
- Power BI Desktop (октябрь 2023 или новее)
- Файл данных Online Retail II.xlsx (2009-2011)

Инструкция:
1. Скачайте репозиторий
2. Откройте Online Retail Analytics.pbix
3. При запросе укажите путь к файлу данных
4. Обновите данные
